# IronWeaveDrama

AI 短剧制作系统。

## 当前进度

剧集库、项目创作空间、分季／分集管理与基础角色档案。

- 中文主页与空状态，支持窄屏布局。
- 默认跟随系统浅色／暗黑模式；右上角按钮可手动切换，浏览器会记住选择。
- 一个项目代表一整部短剧，不是单独一集。
- 点击“创建短剧”填写名称、画面风格（40 个预设，也可自由填写）和画面比例（9:16、16:9、21:9、4:3、3:4、1:1）。
- 画风预设涵盖写实影视、动漫卡通、中国风、国漫现言、绘画艺术、幻想科幻及数字现代风格。
- 创建后显示项目卡片，数据保存在 `data/drama.sqlite`，刷新或重启后仍保留。
- 点击项目卡片进入创作工作台，侧栏分为“创作”和“资源库”，默认进入分季／分集管理。
- 每个项目默认第一季；支持添加季和集、重命名、上下调整顺序，修改后持久保存。
- “剧本”按季列出各集入口；点击集名进入本集页面，剧本和分镜属于该集，资源库由全剧共用。
- 剧本编辑和分镜制作尚未实现，本集页面目前展示空状态。
- 角色资源支持名称建档、卡片列表、名称搜索和每页 50 条分页；超过一页才显示分页。
- 点击角色卡片编辑姓名、年龄、外形呈现、肤色、五官、头发、身高、体型、比例和身份特征；资料由全剧共用，刷新或重启后保留。
- 保存失败保留输入，未保存修改离开页面时提醒；保存资料不会调用 AI。基础角色板区域固定 16:9，画风继承项目。
- 基础角色板下方可选择已保存的文生图 API，点击“生成图片”直接以角色资料和固定四视图模板生成，不弹确认窗；按钮显示“生成中…”并防止重复点击。生成可能计费。仅适用于年龄明确为 18 岁及以上的角色。
- 生成图片直接显示在基础角色板区域，点击图片可打开原图。结果保存在本地 SQLite，刷新或重启后保留；请求失败不丢旧图，也不自动重试。
- “AI修图”展开编辑图片 API 和修图要求，点击“开始修图”后实际编辑当前预览图，可能计费；失败保留原图和输入，不自动重试。
- “清空图像”移除角色预览和列表封面，不修改角色资料、不调用模型；本地图片记录保留，清空状态在刷新或重启后保留。
- 短剧、角色、API 配置卡片及季／集操作区提供“删除”按钮；剧本列表和本集页也可删除该集。点击删除必须确认，取消不执行。
- 首页右上角“设置”进入 API 配置卡片列表；下拉筛选文生图、大语言模型、图生图或编辑图片。
- 点击“添加配置”填写名称、类型、接口地址、密钥和模型；保存后出现卡片，点击卡片查看和编辑。同类型可添加多条，互不覆盖，所有项目共用。
- 保存配置不调用模型；点击“测试模型（可能计费）”并确认后，实际调用所填模型，展示文本回复或测试图片。失败响应、空结果或任务 ID 不算通过，不自动重试。
- 图生图和编辑图片测试需要上传参考图，使用 OpenAI 兼容图片编辑协议，不回退到普通文生图。
- 场景、道具和服饰入口目前仍为空状态。角色参考图上传与关联画布尚未接入；设置页的测试图不会写入角色库。

## 删除内容

- 删除短剧：一并删除其全部季、集、角色及图片，不删除全局 API 配置。
- 删除角色：一并删除资料和全部图片记录，包含“清空图像”后保留的历史图片。
- 删除季：一并删除本季的集；删除集不影响同项目的角色资源。
- 删除 API 配置：移除地址、密钥和模型设置，已有角色及图片不受影响。

确认框会说明删除范围；删除不可撤销，恢复需要已有数据库备份。正在生图或修图的角色及所属短剧暂时不能删除。删除失败保留页面和数据，不自动重试；所有对象 ID 删除后不复用，避免旧卡片或图片链接误指向新记录。

## 本地运行

需要 Node.js 22.13 或更新版本（使用内置 SQLite）。当前没有第三方依赖，无需 `npm install`。

```bash
npm start
```

远程开发时打开 `http://服务器IP:3000`；在服务器本机也可以打开 <http://127.0.0.1:3000>。按 `Ctrl+C` 停止。

端口被占用时：

```bash
PORT=3001 npm start
```

服务默认监听 `0.0.0.0`，允许远程访问。需要在防火墙或云服务器安全组中放行对应端口；按本地自用设计，没有登录鉴权；可访问服务的人能查看和修改项目资料、API 配置。请仅允许可信 IP 访问，不要直接向所有公网用户开放。

## 开发与检查

```bash
npm run dev
npm test
```

开发模式自动重启修改后的服务端 JavaScript；HTML、CSS 和浏览器脚本每次请求时读取，修改后刷新页面即可。

## API 配置

首页点击“设置”，进入 API 配置卡片列表。用类型下拉筛选已有卡片，点击“添加配置”新建，点击卡片进入详情编辑。同类型可以保存多条 OpenAI 兼容配置，每条独立保存。

- **配置名称**：用于识别卡片。
- **API 类型**：文生图、大语言模型、图生图或编辑图片。
- **Base URL**：包含版本前缀的基础地址，程序不会自动补 `/v1`；测试按类型追加聊天、生图或图片编辑接口路径。
- **API Key**：首次配置填写；之后留空保持这条配置的原密钥，填新值则替换。页面和保存响应不会回传已保存的密钥。
- **模型名称**：填写服务使用的模型标识。

修改后先保存，再点击“测试模型（可能计费）”并确认。测试不是读取模型列表，而是一次实际模型请求：

- 大语言模型：`POST /chat/completions`，请求短回复，`max_tokens: 16`，展示实际返回的文本。
- 文生图：`POST /images/generations`，请求一张简单测试图，展示返回图片。
- 图生图／编辑图片：上传一张 PNG、JPEG 或 WebP 参考图（最多 5 MiB），通过 `POST /images/edits` 的 multipart 协议请求一张结果图。非标准 JSON 参考图协议尚未支持。

只有收到有效文本或图片结果才报通过；图片加载失败会显示未通过。HTTP 错误、空结果及仅返回异步任务 ID 不算成功，目前不支持异步任务轮询。文本最多等待 60 秒，图片最多 180 秒；超时或网络失败可能发生在扣费之后，请先查看服务商记录，不会自动重试。测试输入及输出不保存到角色资源。

基础角色板的 16:9 属于生成规则，不是所有 API 的全局尺寸设置，也不强加到通用测试图。

## 角色板生成

在角色详情页保存年龄和外观资料，然后在基础角色板下方选择文生图 API，点击“生成图片”。只有一条配置时自动选中。生成使用项目画风和成人基础四视图模板，不使用设置页的测试提示词。

当前请求 `/images/generations`，尺寸固定 `2560x1440`；模型服务必须支持这个尺寸和同步图片结果。若拒绝参数会显示服务错误，不自动尝试其他尺寸或重复扣费。返回图片地址时下载到本地，不带 API Key，也不跟随重定向。

“AI修图”使用已保存的编辑图片配置，通过 `/images/edits` multipart 上传当前角色板、修图要求和固定模板约束，仍要求输出 16:9。修图不会回退到普通生图。生成或修图期间不能清空，避免重复扣费及回写冲突。

生成结果直接显示在基础角色板区域。若返回比例不是 16:9，或生成期间角色资料已变化，本次结果仍保存供查看，但明确标为未通过，保留原角色板。通过尺寸检查也不代表四视图和身份一致性已经人工确认，请检查画面内容后使用。

密钥以明文保存在 `data/drama.sqlite`，不纳入 Git；请保管好本地数据和备份。设置页无需登录或额外环境变量。
