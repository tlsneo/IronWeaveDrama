# IronWeaveDrama

AI 短剧制作系统。

## 当前进度

剧集库、项目创作空间与分季／分集管理。

- 中文主页与空状态，支持窄屏布局。
- 默认跟随系统浅色／暗黑模式；右上角按钮可手动切换，浏览器会记住选择。
- 一个项目代表一整部短剧，不是单独一集。
- 点击“创建短剧”填写名称、画面风格（40 个预设，也可自由填写）和画面比例（9:16、16:9、21:9、4:3、3:4、1:1）。
- 画风预设涵盖写实影视、动漫卡通、中国风、国漫现言、绘画艺术、幻想科幻及数字现代风格。
- 创建后显示项目卡片，数据保存在 `data/drama.sqlite`，刷新或重启后仍保留。
- 点击项目卡片进入创作工作台，侧栏分为“创作”和“资源库”，默认进入分季／分集管理。
- 每个项目默认第一季；支持添加季和集、重命名、上下调整顺序，修改后持久保存。
- “剧本”按季列出各集入口；点击集名进入本集页面，剧本和分镜属于该集，资源库由全剧共用。
- 剧本编辑和分镜制作尚未实现，本集页面目前展示空状态。
- 资源入口分为角色、场景、道具和服饰，目前均为空状态；尚未接入资源数据、搜索和分页。
- 尚未接入角色创建、关联画布或 AI 服务。

## 本地运行

需要 Node.js 22.13 或更新版本（使用内置 SQLite）。当前没有第三方依赖，无需 `npm install`。

```bash
npm start
```

远程开发时打开 `http://服务器IP:3000`；在服务器本机也可以打开 <http://127.0.0.1:3000>。按 `Ctrl+C` 停止。

端口被占用时：

```bash
PORT=3001 npm start
```

服务默认监听 `0.0.0.0`，允许远程访问。需要在防火墙或云服务器安全组中放行对应端口；当前没有登录鉴权，可访问服务的人都能查看、创建项目和修改季／集；开发时请仅允许可信 IP 访问，不要直接向所有公网用户开放。

## 开发与检查

```bash
npm run dev
npm test
```

开发模式自动重启修改后的服务端 JavaScript；HTML、CSS 和浏览器脚本每次请求时读取，修改后刷新页面即可。

## 目录

```text
src/
  server.js       启动本地服务
  app.js          页面、静态资源与项目创建路由
  database.js     SQLite 存储与升级
  creation.js     季与集的创建、改名、排序
  render-creation.js  创作视图
  html.js         HTML 文本转义
views/
  index.html      剧集库主页与创建弹窗
  library-empty.html  空状态
  project.html    项目创作空间
  resource-empty.html  资源空状态
public/
  styles.css      页面样式
  theme.js        主题切换与偏好保存
  projects.js     项目创建交互
  studio.js       季与集的表单、排序交互
test/
  app.test.js     HTTP 与主页冒烟测试
  theme.test.js   主题切换逻辑测试
  projects.test.js  项目校验与持久保存测试
  projects-ui.test.js  弹窗提交交互测试
  database.test.js  数据库升级与回滚测试
  creation.test.js  季与集的操作、隔离与保存测试
  seasons-migration.test.js  分季数据升级与回滚测试
  studio-ui.test.js  创作表单与排序交互测试
```

`data/` 不纳入 Git。请保留并备份该目录，删除它会丢失已保存的项目、季和集。已有数据库在启动时自动升级，为已有项目补上第一季，不会覆盖项目资料。
