# IronWeaveDrama

AI 剧集创作与制作系统。

以整部剧为项目，按季、集组织创作，角色等资源由全剧共用。支持小说片段改编、剧本编辑、人物与场景提取、共享资源档案、基础角色板和场景参考图生成、服饰／道具素材库、手动定妆，以及可编辑的分镜与时长估算。

## 运行

需要 Node.js 22.13 或更新版本。没有第三方依赖，无需 `npm install`。

```bash
npm start
```

打开 <http://127.0.0.1:3000>；远程访问使用 `http://服务器IP:3000`。按 `Ctrl+C` 停止。

端口被占用时：

```bash
PORT=3001 npm start
```

## 基本使用

1. 在“设置”中添加 API 配置，填写名称、类型、接口地址、密钥和模型。支持多条 OpenAI 兼容配置；地址需包含服务要求的版本路径，程序不会自动补 `/v1`。
2. 创建项目，选择画风和画面比例，在创作空间添加季和集。
3. 进入本集“剧本”，粘贴小说原文、选择大语言模型并生成；剧本和改编说明可以分别编辑、保存。
4. 从本集已保存剧本提取人物与场景，核对、删除错误项后确认关联或新建共享档案。重新提取会重新调用模型，不屏蔽上次删掉的项。
5. 在“基础演员”资源库完善角色档案，可上传身份参考图，再选择对应 API 生成角色板。角色板模板适用于年龄明确为 18 岁及以上的角色，固定 16:9。
6. 在场景资源库完善固定环境描述，可上传环境参考图，再生成无人场景参考图，沿用项目画风与画面比例。人物和场景均无参考图时使用文生图，有参考图时使用图生图；参考图支持 PNG、JPEG、WebP，最多 5 MiB。
7. 在“服饰”“道具”资源库添加名称、说明和参考图，可替换或移除图片。素材由全剧共用，暂不提供素材图片自动生成。
8. 在“定妆”中新建条目，选择一个基础演员及可选的多件服饰／道具，自己填写提示词并先保存；核对页面显示的实际参考图顺序，再选择图生图 API 并点击生成。不会自动搭配、用 LLM 改写提示词或强制四视图；定妆沿用项目画风和画面比例，不覆盖演员基础图。
9. 进入本集“分镜”，选择大语言模型、设置单镜时长上限并生成文字分镜。逐镜核对构图、动作、对白、声音和预计时长，可增删、排序后确认保存；「删除全部镜头」经确认立即清空本集，无需再保存，不影响剧本、共享资源或其他集。全剧时长汇总只计入已确认且依据版本有效的集，并标注尚未规划的部分。镜头图与视频生成尚未接入。

保存内容、上传参考图不会调用模型。生成和“测试模型”可能计费，失败不会自动重试。已有剧本或分镜重新生成时会确认替换；需要保留旧稿时请先自行备份。

定妆生成会发送实际图片文件：先基础演员（优先有效角色板，否则上传参考图），再按编号排列的服饰、道具。已选图片缺失会在调用模型前停止；最多选择 50 件素材，参考图合计不超过 32 MiB。使用已保存的图生图配置，固定向 `/images/edits` 发送 `image[]` 多图字段；接口须支持这一协议，普通单图 API 测试通过不代表多图兼容，不会改单图或自动重试。生成图片和输入版本保留历史；演员、素材或创作依据变化后，旧定妆照标为旧依据，不会自动付费重生成。**定妆暂为独立资源库，尚未绑定到本集出场或分镜。**

剧本生成、人物／场景提取和分镜生成不设本地主动等待时限，完整结果通过校验后才保存。等待期间请勿重复提交；服务商或网关仍可能中断连接。

## 数据与安全

- 数据保存在 `data/drama.sqlite`，刷新或重启后保留；请备份 `data/`，删除该目录会丢失项目资料。
- API 密钥以明文保存在本地数据库中，`data/` 不纳入 Git。请妥善保管数据和备份。
- 删除操作会按确认框说明级联删除相关内容，无法撤销。
- 服务默认监听 `0.0.0.0`，没有登录鉴权。能访问服务的人可以查看和修改资料、使用已保存的 API；请仅允许可信 IP 访问，不要直接向所有公网用户开放。
