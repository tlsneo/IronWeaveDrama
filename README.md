# IronWeaveDrama

AI 剧集创作与制作系统。

以整部剧为项目，按季、集组织创作，角色等资源由全剧共用。支持小说片段改编、剧本编辑、角色档案与角色板生成。

## 运行

需要 Node.js 22.13 或更新版本。没有第三方依赖，无需 `npm install`。

```bash
npm start
```

打开 <http://127.0.0.1:3000>；远程访问使用 `http://服务器IP:3000`。按 `Ctrl+C` 停止。

端口被占用时：

```bash
PORT=3001 npm start
```

## 基本使用

1. 在“设置”中添加 API 配置，填写名称、类型、接口地址、密钥和模型。支持多条 OpenAI 兼容配置；地址需包含服务要求的版本路径，程序不会自动补 `/v1`。
2. 创建项目，选择画风和画面比例，在创作空间添加季和集。
3. 进入本集“剧本”，粘贴小说原文、选择大语言模型并生成；剧本和改编说明可以分别编辑、保存。
4. 在角色资源库建立档案，可上传一张身份参考图，再选择对应 API 生成角色板。角色板模板适用于年龄明确为 18 岁及以上的角色；参考图支持 PNG、JPEG、WebP，最多 5 MiB。

保存内容、上传参考图不会调用模型。生成和“测试模型”可能计费，失败不会自动重试。已有剧本重新生成时会确认替换；需要保留旧稿时请先自行备份。

## 数据与安全

- 数据保存在 `data/drama.sqlite`，刷新或重启后保留；请备份 `data/`，删除该目录会丢失项目资料。
- API 密钥以明文保存在本地数据库中，`data/` 不纳入 Git。请妥善保管数据和备份。
- 删除操作会按确认框说明级联删除相关内容，无法撤销。
- 服务默认监听 `0.0.0.0`，没有登录鉴权。能访问服务的人可以查看和修改资料、使用已保存的 API；请仅允许可信 IP 访问，不要直接向所有公网用户开放。

## 开发

```bash
npm run dev
npm test
```

开发模式自动重启服务端；页面和浏览器资源修改后刷新即可。
