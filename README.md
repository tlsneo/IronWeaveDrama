# IronWeaveDrama

独立的 AI 短剧制作系统，采用单体 Web 应用，不依赖 LocalMiniDrama。

## 当前进度

第一步：剧集库主页。

- 中文主页与空状态，支持窄屏布局。
- 默认跟随系统浅色／暗黑模式；右上角按钮可手动切换，浏览器会记住选择。
- 一个项目代表一整部短剧，不是单独一集。
- “创建短剧”入口暂未开放，没有示例项目或模拟数据。
- 尚未接入数据库、角色管理或 AI 服务。

## 本地运行

需要 Node.js 22 或更新版本。当前没有第三方依赖，无需 `npm install`。

```bash
npm start
```

远程开发时打开 `http://服务器IP:3000`；在服务器本机也可以打开 <http://127.0.0.1:3000>。按 `Ctrl+C` 停止。

端口被占用时：

```bash
PORT=3001 npm start
```

服务默认监听 `0.0.0.0`，允许远程访问。需要在防火墙或云服务器安全组中放行对应端口；当前没有登录鉴权，开发时请仅允许可信 IP 访问，不要直接向所有公网用户开放。

## 开发与检查

```bash
npm run dev
npm test
```

开发模式自动重启修改后的 JavaScript；修改 HTML 或 CSS 后，需要重启服务。

test/
