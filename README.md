# IronWeaveDrama

AI 短剧制作系统。

## 当前进度

剧集库、项目创作空间、分季／分集管理与基础角色档案。

- 中文主页与空状态，支持窄屏布局。
- 默认跟随系统浅色／暗黑模式；右上角按钮可手动切换，浏览器会记住选择。
- 一个项目代表一整部短剧，不是单独一集。
- 点击“创建短剧”填写名称、画面风格（40 个预设，也可自由填写）和画面比例（9:16、16:9、21:9、4:3、3:4、1:1）。
- 画风预设涵盖写实影视、动漫卡通、中国风、国漫现言、绘画艺术、幻想科幻及数字现代风格。
- 创建后显示项目卡片，数据保存在 `data/drama.sqlite`，刷新或重启后仍保留。
- 点击项目卡片进入创作工作台，侧栏分为“创作”和“资源库”，默认进入分季／分集管理。
- 每个项目默认第一季；支持添加季和集、重命名、上下调整顺序，修改后持久保存。
- “剧本”按季列出各集入口；点击集名进入本集页面，剧本和分镜属于该集，资源库由全剧共用。
- 剧本编辑和分镜制作尚未实现，本集页面目前展示空状态。
- 角色资源支持名称建档、卡片列表、名称搜索和每页 50 条分页；超过一页才显示分页。
- 点击角色卡片编辑姓名、年龄、外形呈现、肤色、五官、头发、身高、体型、比例和身份特征；资料由全剧共用，刷新或重启后保留。
- 保存失败保留输入，未保存修改离开页面时提醒；保存资料不会调用 AI。角色板预留区域固定 16:9，画风继承项目。
- 场景、道具和服饰入口目前仍为空状态。参考图上传、角色板生图、关联画布与 AI 服务尚未接入。

## 本地运行

需要 Node.js 22.13 或更新版本（使用内置 SQLite）。当前没有第三方依赖，无需 `npm install`。

```bash
npm start
```

远程开发时打开 `http://服务器IP:3000`；在服务器本机也可以打开 <http://127.0.0.1:3000>。按 `Ctrl+C` 停止。

端口被占用时：

```bash
PORT=3001 npm start
```

服务默认监听 `0.0.0.0`，允许远程访问。需要在防火墙或云服务器安全组中放行对应端口；当前没有登录鉴权，可访问服务的人都能查看、创建项目和修改季／集；开发时请仅允许可信 IP 访问，不要直接向所有公网用户开放。

## 开发与检查

```bash
npm run dev
npm test
```

开发模式自动重启修改后的服务端 JavaScript；HTML、CSS 和浏览器脚本每次请求时读取，修改后刷新页面即可。
