# IronWeaveDrama

AI 短剧制作系统。

## 当前进度

剧集库、项目创作空间、分季／分集管理、本集剧本与基础角色档案。

- 中文主页与空状态，支持窄屏布局。
- 默认跟随系统浅色／暗黑模式；右上角按钮可手动切换，浏览器会记住选择。
- 一个项目代表一整部短剧，不是单独一集。
- 点击“创建短剧”填写名称、画面风格（40 个预设，也可自由填写）和画面比例（9:16、16:9、21:9、4:3、3:4、1:1）。
- 画风预设涵盖写实影视、动漫卡通、中国风、国漫现言、绘画艺术、幻想科幻及数字现代风格。
- 创建后显示项目卡片，数据保存在 `data/drama.sqlite`，刷新或重启后仍保留。
- 点击项目卡片进入创作工作台，侧栏分为“创作”和“资源库”，默认进入分季／分集管理。
- 每个项目默认第一季；支持添加季和集、重命名、上下调整顺序，修改后持久保存。
- “剧本”按季列出各集入口；点击集名进入本集页面，剧本和分镜属于该集，资源库由全剧共用。
- 本集页面可粘贴小说原文，选择已保存的大语言模型配置，点击“生成剧本”改编为可编辑的剧本；原文、剧本和改编说明分别保存。
- “保存剧本”只保存内容，不调用模型；生成前会先保存当前输入。生成可能计费，失败不覆盖旧稿、不自动重试；已有剧本重新生成必须确认替换。分镜制作尚未实现。
- 角色资源支持名称建档、卡片列表、名称搜索和每页 50 条分页；超过一页才显示分页。
- 点击角色卡片编辑姓名、年龄、外形呈现、肤色、五官、头发、身高、体型、比例和身份特征；资料由全剧共用，刷新或重启后保留。
- 保存失败保留输入，未保存修改离开页面时提醒；保存资料不会调用 AI。基础角色板区域固定 16:9，画风继承项目。
- 基础角色板下方支持上传一张身份参考图、预览、替换和移除；上传不调用模型，图片本地保存，刷新或重启后保留。支持 PNG、JPEG、WebP，最多 5 MiB。
- 没有参考图时选择文生图 API；有参考图时自动切换图生图 API 和参考图版提示词，参考身份与五官，不照搬衣服、背景或构图。点击“生成图片”才调用模型，不弹确认窗；按钮显示“生成中…”并防重复操作。仅适用于年龄明确为 18 岁及以上的角色，请使用成年人物的参考图。
- 生成图片直接显示在基础角色板区域，点击图片可打开原图。结果保存在本地 SQLite，刷新或重启后保留；请求失败不丢旧图，也不自动重试。
- “AI修图”打开遮罩编辑器：画笔、橡皮擦、笔刷大小、撤销／重做、清空选区、缩放、平移和修改要求；可下载与原图同尺寸的遮罩 PNG。当前遮罩模型接口待接入，“开始修图”禁用，不调用模型、不冒充修图成功。
- “清空图像”移除角色预览和列表封面，不修改角色资料、不调用模型；本地图片记录保留，清空状态在刷新或重启后保留。
- 短剧、角色、API 配置卡片及季／集操作区提供“删除”按钮；剧本列表和本集页也可删除该集。点击删除必须确认，取消不执行。
- 首页右上角“设置”进入 API 配置卡片列表；下拉筛选文生图、大语言模型、图生图或编辑图片。
- 点击“添加配置”填写名称、类型、接口地址、密钥和模型；保存后出现卡片，点击卡片查看和编辑。同类型可添加多条，互不覆盖，所有项目共用。
- 保存配置不调用模型；点击“测试模型（可能计费）”并确认后，实际调用所填模型，展示文本回复或测试图片。失败响应、空结果或任务 ID 不算通过，不自动重试。
- 图生图和编辑图片测试需要上传参考图，使用 OpenAI 兼容图片编辑协议，不回退到普通文生图。
- 场景、道具和服饰入口目前仍为空状态；设置页的测试图不会写入角色库。

## 删除内容

- 删除短剧：一并删除其全部季、集、剧本、角色及图片，不删除全局 API 配置。
- 删除角色：一并删除资料和全部图片记录，包含“清空图像”后保留的历史图片。
- 删除季：一并删除本季的集及剧本；删除集会删除本集原文、剧本和改编说明，不影响同项目的角色资源。
- 删除 API 配置：移除地址、密钥和模型设置，已有角色及图片不受影响。

确认框会说明删除范围；删除不可撤销，恢复需要已有数据库备份。正在生图的角色及所属短剧暂时不能删除；剧本生成期间不能删除该集、所属季或短剧。删除失败保留页面和数据，不自动重试；所有对象 ID 删除后不复用，避免旧卡片或图片链接误指向新记录。

## 本地运行

需要 Node.js 22.13 或更新版本（使用内置 SQLite）。当前没有第三方依赖，无需 `npm install`。

```bash
npm start
```

远程开发时打开 `http://服务器IP:3000`；在服务器本机也可以打开 <http://127.0.0.1:3000>。按 `Ctrl+C` 停止。

端口被占用时：

```bash
PORT=3001 npm start
```

服务默认监听 `0.0.0.0`，允许远程访问。需要在防火墙或云服务器安全组中放行对应端口；按本地自用设计，没有登录鉴权；可访问服务的人能查看和修改项目资料、API 配置。请仅允许可信 IP 访问，不要直接向所有公网用户开放。

## 开发与检查

```bash
npm run dev
npm test
```

开发模式自动重启修改后的服务端 JavaScript；HTML、CSS 和浏览器脚本每次请求时读取，修改后刷新页面即可。

## API 配置

首页点击“设置”，进入 API 配置卡片列表。用类型下拉筛选已有卡片，点击“添加配置”新建，点击卡片进入详情编辑。同类型可以保存多条 OpenAI 兼容配置，每条独立保存。

- **配置名称**：用于识别卡片。
- **API 类型**：文生图、大语言模型、图生图或编辑图片。
- **Base URL**：包含版本前缀的基础地址，程序不会自动补 `/v1`；测试按类型追加聊天、生图或图片编辑接口路径。
- **API Key**：首次配置填写；之后留空保持这条配置的原密钥，填新值则替换。页面和保存响应不会回传已保存的密钥。
- **模型名称**：填写服务使用的模型标识。

修改后先保存，再点击“测试模型（可能计费）”并确认。测试不是读取模型列表，而是一次实际模型请求：

- 大语言模型：`POST /chat/completions`，请求短回复，`max_tokens: 16`，展示实际返回的文本。
- 文生图：`POST /images/generations`，请求一张简单测试图，展示返回图片。
- 图生图／编辑图片：上传一张 PNG、JPEG 或 WebP 参考图（最多 5 MiB），通过 `POST /images/edits` 的 multipart 协议请求一张结果图。非标准 JSON 参考图协议尚未支持。

只有收到有效文本或图片结果才报通过；图片加载失败会显示未通过。HTTP 错误、空结果及仅返回异步任务 ID 不算成功，目前不支持异步任务轮询。文本最多等待 60 秒，图片最多 180 秒；超时或网络失败可能发生在扣费之后，请先查看服务商记录，不会自动重试。测试输入及输出不保存到角色资源。

基础角色板的 16:9 属于生成规则，不是所有 API 的全局尺寸设置，也不强加到通用测试图。

## 本集剧本

从侧栏“剧本”或分季／分集管理进入某一集，在“小说原文”粘贴本集要改编的片段，选择大语言模型 API，点击“生成剧本”。只有一条大语言模型配置时自动选中，没有配置则提示设置并禁用生成。

固定提示词位于 `prompts/script/novel-to-script.js`。本阶段做影视改编，不是小说逐句转录：保留核心人物、关系、主要动机、矛盾与情感走向，允许删减、重组事件和场景，改写或新增对白，将心理叙述重新设计成动作与人物互动，必要时补充过渡小戏、合理场面设定及功能性配角。重要改写和新增在改编说明中交代，不擅自另造主线、颠倒核心人物或续写未提供的结果。

按改编后的实际时空分场，不逐项搬运原文或把每段心理都变成独白；展开的回忆、预想保持清楚的叙事层次，不把多个完整事件和对白装进一个大场景或蒙太奇。

正文使用“第一集《标题》”与 `1-1、1-2` 这样的场号，集序号取本集在所属季中的实际顺序，标题沿用原文。动作与对白分段，明确对白归属、屏幕消息及现实／回忆／预想边界。不固定场数，不强制反转或结尾钩子，不做时长、分镜、运镜、资源抽取或后续剧情扩写。修改提示词不会自动改变已保存的稿件，只有下次手动生成才使用新规则。

原文、剧本正文和改编说明是三个独立字段，都可以编辑。“保存剧本”不会调用模型；点击生成会先保存当前输入，成功后保存并显示新剧本。已有剧本或说明重新生成时，先确认是否允许成功结果替换当前稿件；没有历史版本库，确认替换前请自行保留想留下的稿件。生成失败保留原文和旧稿，未保存修改离开时提醒。

使用 OpenAI 兼容 `POST /chat/completions`，非流式调用，最多等待 180 秒，输出 token 上限为 8192。固定规则放在 system 消息，原文单独放在 user 消息。模型需返回包含字符串 `script` 和 `notes` 的 JSON；空回复、异步任务、截断或无效格式不算成功，不自动续写、换协议或重试。格式不合格、并发内容变化或本地保存失败时，会单独显示可取回的模型文本，不覆盖现有稿件。

原文最多 30000 字、剧本正文最多 60000 字、改编说明最多 10000 字；过长材料请分段处理。输入上限不保证模型上下文足够，需按所选模型能力使用。不同集独立保存，刷新或重启后保留。旧页面不能覆盖新版本，同集生成期间不能重复调用、保存或删除该集及父级。

## 角色板生成

在角色详情页保存年龄和外观资料。可在基础角色板下方上传一张身份参考图，上传后显示缩略图，支持替换和移除。没有参考图时选择文生图 API；有参考图时自动切换为图生图 API。当前类型只有一条配置时自动选中，没有对应配置则禁用生成并提示设置，不回退其他类型，也不修改已有配置的类型。

点击“生成图片”才请求模型，上传、替换、移除参考图或保存资料都不会自动生成。两种方式都使用项目画风和成人基础四视图模板；参考图版提示词以脸部身份为锚，已填写的发型、发色、体型等基础信息用于明确约束，不复制参考图的衣服、背景、姿势、构图或画风。不会自动识图填写角色资料，也不会依据图片猜年龄。

文生图请求 `/images/generations`；参考生图使用 OpenAI 兼容 `/images/edits` multipart，将本地参考图的实际字节、提示词和模型一起提交，不是只发送文件名或参考图 ID。尺寸均固定 `2560x1440`；模型服务必须支持这个尺寸、参考图输入（图生图）和同步图片结果。若拒绝参数会显示服务错误，不自动换协议、尝试其他尺寸或重复扣费。返回图片地址时下载到本地，不带 API Key，也不跟随重定向。

生成结果保存完整提示词和实际使用的参考图 ID。替换、移除参考图不改变已有角色板；历史参考图保留，便于追溯旧结果。旧页面不能提交已经变化的参考图，生成期间不能替换或移除。删除角色或短剧会级联删除其全部历史参考图。

生成期间不能清空，避免重复扣费及回写冲突。

## 遮罩修图

在已有角色板下点击“AI修图”。画笔涂选需要修改的位置，橡皮擦去除选区；支持笔刷大小调整、撤销／重做、清空选区、滚轮或按钮缩放、平移和适合窗口。红色半透明选区是独立遮罩，不修改原图。键盘也可操作：画布聚焦后用方向键移动定位点，空格涂抹／擦除，加减键缩放；平移模式下方向键移动画面。

右侧可以选择编辑图片配置和填写修改要求。当前只完成本地编辑交互，真实遮罩模型接口尚未接入，“开始修图”保持禁用；直接请求修图接口也会明确返回 503，不会付费、不回退整图编辑或普通生图。设置页的编辑图片测试仍是单张参考图测试，通过不代表支持遮罩。

“下载遮罩”导出与原图同尺寸的 PNG，白色代表选区、黑色代表保留区；具体模型需要的透明度或遮罩协议在对接时再转换。原图不会混入遮罩。关闭后重新打开同一张图会保留当前页内的选区与要求；刷新或换图会清除。编辑器目前支持最多 1600 万像素。修图结果比较／采用及额外参考图上传尚未实现。

生成结果直接显示在基础角色板区域。若返回比例不是 16:9，或生成期间角色资料已变化，本次结果仍保存供查看，但明确标为未通过，保留原角色板。通过尺寸检查也不代表四视图和身份一致性已经人工确认，请检查画面内容后使用。

密钥以明文保存在 `data/drama.sqlite`，不纳入 Git；请保管好本地数据和备份。设置页无需登录或额外环境变量。
